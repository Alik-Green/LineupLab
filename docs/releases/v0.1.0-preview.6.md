# LineupLab 0.1.0-preview.6

Sixth Windows + Android prerelease. Source: `85170a7b7056b1acd348a175f565f4c02d067547`.

## Highlights

- **Minimap crash/selection/zoom/layout fixes.** The pan/pointer-cancel/resize/unmount crash is removed at the gesture-state source; map dragging no longer selects text or shows selection chrome. Zoom lays out the bitmap at native CSS size and keeps SVG markers/callouts sharp. Browse keeps the map square, reachable and correctly aligned at fullscreen, laptop, half-size and narrow windows.
- **Cleaner Create workspace.** The old top progress/Back/Next bar is replaced by compact section navigation: Setup, Capture, Pins, Finish. Setup uses direct mode toggles; Pins is Start/End plus an optional second start only when the mode needs it; annotation is a compact tool/canvas/properties workspace; the final stage merges Details/Review without Notes/Author/Tags editing while preserving stored values.
- **Callouts and map artwork.** Minimap callout labels can be toggled; the Map selector uses loading-screen/list artwork rather than the tactical minimap. Difficulty dots are coloured by position: green, orange, red.
- **Image-proportioned overlays.** Normal overlay height follows the decoded image plus measured compact chrome; Minimal mode preserves the exact image aspect and optional outline. Outline thickness is adjustable (default 3px, range 1–12px), margin is one combined value, and normal mode shows discreet hotkey hints.
- **Android Download actually populates Browse.** Connect & download connects, fetches, persists and refreshes the visible library, including after relaunch. Discovery only shows live `/health`-verified desktops; stopping sharing and desktop exit unregister mDNS and shut down the server. The obsolete access-code desktop connection panel is removed from the UI; configured codes remain supported by the core.

## Compatibility

Stored lineups, legacy ZIP packs, per-throw data, legacy pin/site/mode values and overlay settings remain supported. Removed Create fields are preserved on existing records rather than deleted. Phone downloads remain one-way and additive; remote tombstones do not erase downloaded phone copies.

## Install / upgrade caveats

- Windows x64 NSIS installer is **unsigned** (SmartScreen warning expected). Requires Windows 10 2004+/11 and WebView2; Valorant Borderless/Windowed only.
- Android companion is **arm64-v8a only**, Android 8.0+ (API 26), target API 36, NDK r28, 16 KB alignment, signed with an **ephemeral preview key**. If the previous preview used a different ephemeral key, uninstall/reinstall and re-connect; back up first. Allow “install unknown apps” for the browser/file manager you use.
- No auto-update. Verify downloads with the attached `SHA256SUMS.txt`.
