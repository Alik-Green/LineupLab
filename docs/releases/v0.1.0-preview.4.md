# LineupLab 0.1.0-preview.4

Fourth Windows + Android prerelease, addressing the latest desktop/mobile feedback batch. Source: `99fc9664aefece0f6dc1745c4d019d43475e1ba4`.

## Download lineups to your phone (no pairing code)

1. Desktop: **Settings → Sharing → Start sharing**. Note the `http://<desktop-ip>:8765` address.
2. Android: bottom nav **Download** → enter that address → **Connect & download**.
3. The phone saves all non-duplicate lineups/images for permanent offline browsing. **Update downloads** fetches new content and retries missing media.

No pairing code is required by default. Older/code-protected desktops still work via **Advanced → Access code**.

**Security trade-off:** sharing is off until you start it, but while it is on anyone who can reach that address can read the library. Plain HTTP is unencrypted. Use a trusted LAN only, never port-forward, and stop sharing when finished. Home addresses usually start `192.168.`, `10.`, or `172.16–31.`; the reported `192.181.x.x` is flagged as non-private.

## What changed

- **Phone downloads:** fixed the `404 /images/` failure caused by blank/invalid media hashes; additive one-way download with progress, warnings and retry; remote deletions do not erase phone copies; notch/cutout safe-area padding; empty-map “no lineups match” now recovers instead of opening a grey screen.
- **ZIP import:** real reading/decompression progress (bytes + current entry), not just later validation/media stages.
- **Browse/Create:** Map / Agent / Ability are three adjacent square icon pickers; Team Deathmatch/range maps removed from choices; short windows keep the minimap reachable.
- **Minimap:** zoom/pan transforms map art and markers together; pin placement accounts for letterboxing/zoom/pan; stand and landing markers with optional toggles; Create pins simplified to Stand, Land, optional second stand and bounce diamonds.
- **Create:** all Sova abilities exposed (including Recon Bolt); Valorant-style charge bars (1st/2nd/3rd/Full) + bounce diamonds; throw type per aim capture; sites A/B/Mid (+C on three-site maps); **Save & create another** retains map/agent/ability/mode/side/site; location-aware titles use optional callouts and fall back to site.
- **Overlay:** size/margin fields can be empty while typing and clamp on blur; **Learn** mode for a selected lineup with image hotkeys and stand/land map; **Minimal** image-only mode with optional outline (Alt+I); Create shows the current capture large with a compact checklist.

## Compatibility

Legacy ZIP packs and lineup data remain supported. Desktop two-way sync semantics are unchanged; the phone Download path is explicitly one-way/additive. Existing code-protected servers are not bypassed.

## Verification

- Green same-revision CI: Windows installer + Ubuntu/core checks; Android APK built in CI.
- Local: TypeScript, desktop/mobile production builds, 32 UI unit tests, 32 Rust integration tests, 25 Playwright checks (desktop + Android viewports).
- Not validated on physical Windows/Android hardware or in live gameplay. Location naming falls back to site when no normalized callout data exists; no walkable-path graph is bundled.

## Install / upgrade caveats

- Windows x64 NSIS installer is **unsigned** (SmartScreen warning expected). Requires Windows 10 2004+/11 and WebView2; Valorant Borderless/Windowed only.
- Android companion APK is signed with an **ephemeral preview key**. Upgrading from Preview 1/2/3 requires uninstall/reinstall and re-connecting; back up first. Min Android 8 (API 26).
- No auto-update. Verify downloads with the attached `SHA256SUMS.txt`.
