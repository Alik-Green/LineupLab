# LineupLab 0.1.0-preview.5

Fifth Windows + Android prerelease. Source: `d02376ca44af7a720a204dd2fc1479c0e9d5baed`.

## P0 fixes

- **Minimap no longer blanks to a solid colour.** Downloaded/legacy lineups can omit render-critical collections (`bounces`, `slots`, `tags`, `steps`, `throws`). Those are now normalized before rendering, a render error boundary keeps the app usable if a future bad record appears, and marker hit-testing resolves the nearest lineup point at stage level so overlapping transparent hit circles cannot steal or swallow clicks. Desktop and phone regressions cover background clicks, stand/landing markers, malformed legacy data, Close/Back and runtime errors.
- **Android install compatibility.** Preview 5 ships an **arm64-v8a-only** companion APK instead of the earlier universal APK. Modern 64-bit phones (including Pixel 9) have reported “can't install” failures with 32-bit/universal native packaging; the release job now rejects any APK containing non-arm64 libraries. The APK targets API 36, minimum API 26, uses NDK r28 and 16 KB ELF/ZIP alignment, and is signed with an ephemeral preview certificate after CI verification. See `docs/ANDROID_INSTALL.md`.

## What changed

- **Browse/Create selectors:** Map / Agent / Ability remain three adjacent squares, with artwork filling most of each square.
- **Minimap:** toolbar tooltips render in a viewport-safe portal; the path toggle draws every visible throw path continuously while active; zoom scales map art and markers together with zoom-compensated marker sizes and full-resolution source icons.
- **Maps:** every TDM/practice map is excluded by UUID and name, explicitly including District, Kasbah, Piazza, Drift, Glitch, The Range and Basic Training.
- **Lineup viewer:** near-full-screen popup with small margins, real image zoom/pan/reset, populated capture tabs only (no empty optional second-stand/second-aim tabs), and Escape/Back/Close support.
- **Cards:** omit throw type, charge and bounce details.
- **Create:** charge/bounce controls live on each aim capture and persist per throw, so double shocks can use independent settings; single-throw modes hide Second stand/Second aim; point-selection tools are Stand / Land / optional second stand only (no Bounce or Pan/zoom tool); stages and Back/Next/save share one top bar with no duplicate bottom navigation.
- **Titles:** auto-generated from the nearest stand and landing callouts using bundled normalized English callout data for 13 standard maps, with an honest site-based fallback when no usable callout exists.

## Compatibility

Legacy ZIP packs and lineup data remain supported. Missing optional collections are normalized at the UI boundary; existing per-throw data is preserved and legacy lineup-level charge/bounce attributes migrate into each throw when no per-throw value exists. Desktop two-way sync and the phone's one-way additive Download path are unchanged.

## Install / upgrade caveats

- Windows x64 NSIS installer is **unsigned** (SmartScreen warning expected). Requires Windows 10 2004+/11 and WebView2; Valorant Borderless/Windowed only.
- Android companion is **arm64-v8a only**, Android 8.0+ (API 26), signed with an **ephemeral preview key**. Upgrading from Preview 1–4 requires uninstall/reinstall and re-connecting; back up first. Allow “install unknown apps” for the browser/file manager you use.
- No auto-update. Verify downloads with the attached `SHA256SUMS.txt`.
