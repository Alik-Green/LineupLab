# LineupLab 0.1.0-preview.7

Seventh Windows + Android prerelease. Source: `b5f2d546de6e6feeac884a56c1ec50cbf71aee28`.

## Highlights

- **Android Download unblocked.** Library, catalog and mode refreshes are independent, so an offline/slow catalog can no longer leave the spinner running or hide downloaded lineups. Download now transfers the desktop's cached catalog over authenticated LAN `GET /catalog`; phone map/agent/ability options no longer depend on reaching `valorant-api.com`. Downloaded drafts are visible in the companion, stale map filters are cleared, and a post-download readback fails loudly if Browse cannot display saved records.
- **Minimap zoom/pan fixed.** Wheel zoom anchors on the cursor using a measured rectangular stage and fixed unzoomed base. Pan clamping uses the scaled canvas, so every edge/corner of the map remains reachable when zoomed.
- **Picker and large-screen layout.** Square map/agent/ability picker labels and gradients sit flush across the full bottom edge. The 1920px page cap is removed, so Browse/Create fill 2560px-wide windows instead of leaving a large left margin.
- **Annotate workspace and alignment.** Annotating fills the viewport under the top bar, hides the Create rail, and keeps tools/canvas/properties usable at 720×450 and fullscreen. Annotation SVG/hit layers and pointer math use the exact decoded-image contain frame, keeping circles/lines/lenses aligned across window sizes and overlay ratios.
- **Settings reliability.** Capture settings use the stale-closure-safe save pattern and surface failures; overlay click-through remains ON by default with a regression test.

## Compatibility

Stored lineups, legacy ZIP packs, annotations, per-throw data, legacy pin/site/mode values and overlay settings remain supported. Phone downloads remain one-way and additive; remote tombstones do not erase downloaded phone copies. Older desktops without `GET /catalog` still download lineups/images; the phone keeps its local catalog.

## Install / upgrade caveats

- Windows x64 NSIS installer is **unsigned** (SmartScreen warning expected). Requires Windows 10 2004+/11 and WebView2; Valorant Borderless/Windowed only.
- Android companion is **arm64-v8a only**, Android 8.0+ (API 26), target API 36, NDK r28, 16 KB alignment, signed with an **ephemeral preview key**. If the previous preview used a different ephemeral key, uninstall/reinstall and re-connect; back up first. Allow “install unknown apps” for the browser/file manager you use.
- No auto-update. Verify downloads with the attached `SHA256SUMS.txt`.
