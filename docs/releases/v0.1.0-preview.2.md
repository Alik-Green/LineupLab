# LineupLab 0.1.0 Preview 2 — redesigned desktop + Android companion

This prerelease packages the completed M1–M8 redesign. Both downloadable apps are built from the same source revision: [`18bceb1c5727ed264b8fc0cb70296644e6f4ea9e`](https://github.com/Alik-Green/LineupLab/commit/18bceb1c5727ed264b8fc0cb70296644e6f4ea9e). Settings → About identifies this release as `0.1.0-preview.2`; native installer/package metadata remains numeric `0.1.0`.

## Downloads

- **Windows x64:** `LineupLab-0.1.0-preview.2-x64-setup.exe` — NSIS installer for Windows 10 version 2004+ and Windows 11, with Microsoft Edge WebView2 bootstrapping.
- **Android:** `LineupLab-Companion-0.1.0-preview.2.apk` — universal companion APK for Android 8.0+ / API 26+, package `app.lineuplab.companion`.
- **Integrity:** `SHA256SUMS.txt` — checksums for the installer and APK. The packaging workflow appends them after validating and signing the artifacts.

The Android app is a **browse/pair/sync companion**, not a second lineup editor. Create and edit on Windows, pair over the local network, pull a read-only copy to the phone, and browse it offline. It has no overlay, game capture or global hotkeys.

## What changed

- Unified desktop/Android visual system: tactical-minimal styling, bundled fonts, consistent chips/buttons/dialogs/navigation, calmer browse/detail pages and a guided Create wizard.
- Cache-first catalog and image loading with retries, explicit placeholders, background asset preparation, progress and asset diagnostics. The native Windows catalog role-icon conversion is fixed so the desktop installer can compile.
- Clearer minimaps, annotation controls and image zoom; keyboard-accessible minimap markers and larger annotation hit areas.
- Redesigned Import/Export and tabbed Settings; desktop control targets are at least 40px and Android targets at least 48px.
- Refreshed overlay and live-draft behavior, including readable notes, comfort preferences and a dismissible live-update indicator.
- Android bottom navigation, touch-friendly controls, pairing/sync settings, offline browsing and safer empty/error states.
- Core lineup schema, legacy ZIP compatibility and existing hotkey defaults/semantics are preserved.

## Install and upgrade

### Windows

1. Back up your library with **Import / Export → Export** before replacing an older preview.
2. Download the `.exe`, verify its SHA-256 against `SHA256SUMS.txt`, and run the installer.
3. The installer is **not Authenticode-signed**. Windows SmartScreen may warn about an unknown publisher; inspect the file/source and make your own trust decision rather than disabling protection globally.
4. Launch LineupLab. For the overlay, use Valorant **Borderless** or **Windowed** mode; exclusive fullscreen is not supported. WebView2 and local network access may be required.

### Android / upgrading Preview 1

1. Keep the Windows library as the source of truth and export a backup first.
2. Preview 1 used an ephemeral signing key that was discarded. Preview 2 cannot be installed over it as a signed in-place update. **Uninstall the old companion**, then install the new APK; this removes the companion's local synced copy and pairing settings.
3. Allow installation from the browser/file manager you used, verify the APK checksum, install, then pair again with the updated Windows app and pull a fresh sync.
4. Phone and desktop must be reachable on the same local network for pairing/sync. Client isolation, VPNs or firewall rules can prevent discovery; manual desktop address entry is available.

Checksum commands:

```powershell
Get-FileHash .\LineupLab-0.1.0-preview.2-x64-setup.exe -Algorithm SHA256
Get-FileHash .\LineupLab-Companion-0.1.0-preview.2.apk -Algorithm SHA256
```

```bash
sha256sum -c SHA256SUMS.txt
```

## Preview limitations — please read

- **No physical Windows gameplay or physical Android-device validation has been performed.** CI compilation, browser automation and viewport/accessibility checks are not a substitute for testing the installer, overlay beside Valorant, Android WebView behavior, LAN sync, sleep/resume or battery use on real devices.
- The Windows installer is unsigned. The APK is aligned and signed with a **temporary self-signed preview key generated for this release and then discarded**, not a production/upload key. Future preview keys may again require uninstall/re-pair. Do not treat these builds as store-ready or production-signed.
- No automatic update service is configured. Download future releases manually and back up first.
- Catalog/media availability depends on upstream services and local cache state; placeholders/diagnostics are intentional when assets cannot be fetched.
- This is an unofficial companion tool. Use the supported window modes and review the manual checks in [`docs/WINDOWS_TEST_PLAN.md`](https://github.com/Alik-Green/LineupLab/blob/18bceb1c5727ed264b8fc0cb70296644e6f4ea9e/docs/WINDOWS_TEST_PLAN.md) before relying on it in a match.
