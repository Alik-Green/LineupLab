# LineupLab 0.1.0 Preview 3 — import progress, Browse pickers, 1440p/DPI overlay fix

This prerelease fixes the three reported issues on top of the Preview 2 redesign. Both downloadable apps are built from the same source revision: [`3dae13c6f39ff78b89a331a2c91ec6065132bc0e`](https://github.com/Alik-Green/LineupLab/commit/3dae13c6f39ff78b89a331a2c91ec6065132bc0e). Settings → About identifies this release as `0.1.0-preview.3`; native installer/package metadata remains numeric `0.1.0`.

## Downloads

- **Windows x64:** `LineupLab-0.1.0-preview.3-x64-setup.exe` — NSIS installer for Windows 10 version 2004+ and Windows 11, with Microsoft Edge WebView2 bootstrapping.
- **Android:** `LineupLab-Companion-0.1.0-preview.3.apk` — universal companion APK for Android 8.0+ / API 26+, package `app.lineuplab.companion`.
- **Integrity:** `SHA256SUMS.txt` — checksums for the installer and APK. The packaging workflow appends them after validating and signing the artifacts.

The Android app remains a **browse/pair/sync companion**, not a second lineup editor. Create and edit on Windows, pair over the local network, pull a read-only copy to the phone, and browse it offline.

## What changed since Preview 2

### Pack import

- Import now runs off the UI thread and reports staged progress: reading ZIP, validating entries, copying media, writing lineups, completion. Determinate steps show current/total; indeterminate steps animate accessibly and respect reduced motion.
- Failures stay visible in a persistent error panel with the file name and core error message instead of only a transient toast. Preview/commit controls are disabled while busy.
- The preview summary explains new/newer/identical/error counts and why nothing may be selected by default, with a “Select all valid” action. Import reports now match the core report shape (imported/skipped/copied/overwritten/errors/warnings).
- Legacy ZIP compatibility and the transactional import/undo path are preserved. If a particular old pack still fails, the new error panel shows the specific reason; please share that pack/error for a targeted fixture.

### Browse

- Map, Agent and Ability are now compact buttons showing the current value. Clicking opens a full picker dialog with all choices, search and role filters for agents; favorite-agent pinning is retained.
- The left panel no longer squeezes permanent map/agent/ability grids above the minimap, giving the map and lineup cards more room. Android uses the same current-value picker pattern with touch-sized targets.

### Overlay placement

- The desktop shell now enumerates real monitors and uses the selected monitor’s physical size, origin and scale factor instead of hardcoding 1920×1080.
- Overlay margins/width/height are treated as logical pixels and converted to physical pixels per monitor, with clamping inside the selected display. This fixes 2560×1440 placement and mixed-DPI multi-monitor setups.
- Settings → Overlay shows the detected monitor, physical/logical resolution, scaling and computed logical position, plus a monitor selector and “Reapply placement”. Saved placement is applied at startup.

## Install and upgrade

1. Back up the Windows library with **Import / Export → Export** before replacing an older preview.
2. Download the installer/APK for your platform and verify SHA-256 against `SHA256SUMS.txt`.
3. The Windows installer is **not Authenticode-signed**; SmartScreen may warn about an unknown publisher. Inspect the file/source and make your own trust decision rather than disabling protection globally.
4. Android Preview 1/2 used ephemeral signing keys that were discarded. Preview 3 cannot be installed over them as a signed in-place update. **Uninstall the old companion**, install Preview 3, then pair again and pull a fresh sync. This removes only the companion’s local synced copy/pairing settings; keep Windows as the source of truth.
5. For the overlay, use Valorant **Borderless** or **Windowed** mode. After installing, open Settings → Overlay, choose the correct monitor, and use “Reapply placement” if the window was already open.

Checksum commands:

```powershell
Get-FileHash .\LineupLab-0.1.0-preview.3-x64-setup.exe -Algorithm SHA256
Get-FileHash .\LineupLab-Companion-0.1.0-preview.3.apk -Algorithm SHA256
```

```bash
sha256sum -c SHA256SUMS.txt
```

## Preview limitations — please read

- **No physical Windows gameplay or physical Android-device validation has been performed.** CI compilation, browser automation and viewport/accessibility checks are not a substitute for testing the installer, overlay beside Valorant, Android WebView behavior, LAN sync, sleep/resume or battery use on real devices.
- The Windows installer is unsigned. The APK is aligned and signed with a **temporary self-signed preview key generated for this release and then discarded**, not a production/upload key. Future preview keys may again require uninstall/re-pair. Do not treat these builds as store-ready or production-signed.
- No automatic update service is configured. Download future releases manually and back up first.
- Catalog/media availability depends on upstream services and local cache state. LAN sync requires phone and desktop to be reachable on the same local network; client isolation, VPNs or firewall rules can prevent discovery.
- This is an unofficial companion tool. Review [`docs/WINDOWS_TEST_PLAN.md`](https://github.com/Alik-Green/LineupLab/blob/arena/e082cc85-lineuplab/docs/WINDOWS_TEST_PLAN.md) before relying on it in a match.
